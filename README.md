## 🌟 Featured Projects

### 🌍 TripMate AI — Multi-Agent Travel Planner

[![Repository](https://img.shields.io/badge/View_Project-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/Rajesh241199/TripMate-AI---Multi-Agent-Travel-Planner-)

An intelligent multi-agent travel planning application built using **LangGraph, FastAPI, Groq LLMs, MCP, and PostgreSQL**.

**Key Features:**
- Supervisor-based orchestration of specialized AI agents
- Flight, hotel, transport, and weather research
- Personalized day-by-day itinerary generation
- Automated budget estimation and optimization
- Route continuity and travel validation
- Human-in-the-loop review and approval
- PostgreSQL-backed workflow checkpointing

**Tech Stack:** Python, LangGraph, FastAPI, Groq, MCP, PostgreSQL, JavaScript
